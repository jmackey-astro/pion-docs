PION can be compiled from source on a number of systems, and depends on a few libraries. This page describes how to get PION installed on a Debian-based linux system such as Debian or Ubuntu, and on OS X with macports for support programmes.

Getting Source code

PION will soon be available from https://git.dias.ie/compastro/pion, but currently this is a private repo; if you want access send a request to info@pion.ie.

System requirements and support libraries

On all systems you will need a C++ compiler such as g++, an MPI implementation such as MPICH or OpenMPI for parallel compilation and execution. If you are downloading from the git repo, you will also need git. A few libraries are needed to run PION:
  • Microphysics is handled by the CVODE solver, part of the SUNDIALS suite of solvers. At present PION works with the version of SUNDIALS in debian 9, version 2.5, and other 2.X releases. This is significantly behind the release cycle of SUNDIALS. It will be updated to version 3.X once development is moved to debian 10 systems.
  • Data I/O can use ASCII text, FITS, and SILO, which are appropriate for different situations. Parallel execution on HPC systems should use SILO because it is built on the HDF library and has good performance on supercomputers. SILO uses version 4.10.2, FITS uses version 3.390 but should work with all 3.x versions.
  • Interpolation routines use the spline functions of the GNU Scientific Library (GSL).
FITS, SILO and CVODE can either use system libraries or self-compiled libraries. The GSL must be present as a system library.

Debian/Ubuntu

Ubuntu 18.04 and Debian 9 haver the same package names. Newer versions are currently not yet working with PION.
  • First install the required packages: 
     $ apt install libcfitsio-bin libcfitsio-dev libsilo-dev libsilo-bin python-silo \
   libsundials-dev openmpi-bin openmpi-common curl libhdf5-serial-dev git libgsl-dev
    In principle mpich could also be used as the MPI C++ compiler, but one of the silo libraries depends explicitly on the openmpi version of the HDF5 libraries, so the mpich compiler doesn't work with the silo library.
  • If you have SILO, FITS, GSL and SUNDIALS installed as .deb packages, then you don't need to compile any extra libraries.
  • Download PION (see above) into a directory <pion>
  • Change directory from the PION root directory <pion> to bin_serial/ and run ./compile_code.sh.
  • This should generate executables in directory <pion> for initial condition generation icgen_serial, icgen_NG_serial, and simulation pion_serial and pion_NG_serial. If there were errors and the executables were not generated then some troubleshooting is needed.
  • Change directory from the PION root directory <pion> to bin_parallel/ and run ./compile_code.sh.
  • Similary to the serial version, this should generate MPI-parallelised executables in directory <pion> for initial condition generation, namely icgen_pllel and icgen_NG_pllel, and simulation, pion_parallel and pion_NG_parallel.

OS X

PION has been tested on OS X Mojave (10.14.6) with software installed via the macports framework. The MPI compiler used is mpich. It is compiled with statically linked libraries.
  • Download PION (see above) into a directory <pion>
  • Change directory from PION root directory <pion> to extra_libraries/.
  • Run bash install_all_libs.sh to download and generate libraries for compatible versions of SILO, SUNDIALS and FITS.
  • Check that the headers exist for all three packages in extra_libraries/include/ and the libraries in extra_libraries/lib. If not, then some troubleshooting is needed.
  • Change directory from the PION root directory <pion> to bin_serial/ and run ./compile_code.sh.
  • This should generate executables in directory <pion> for initial condition generation icgen_serial, icgen_NG_serial, and simulation pion_serial and pion_NG_serial. If there were errors and the executables were not generated then some troubleshooting is needed.
  • Change directory from the PION root directory <pion> to bin_parallel/ and run ./compile_code.sh.
  • Similary to the serial version, this should generate MPI-parallelised executables in directory <pion> for initial condition generation, namely icgen_pllel and icgen_NG_pllel, and simulation, pion_parallel and pion_NG_parallel.
